# Product Vision

## 最終產品一句話

Personal Asset OS 是以個人總資產為核心、每天願意記、月底對得起來，並能清楚回答資產與可用現金狀態的本機財務作業系統。

## 核心使用者

- 第一位且目前唯一的正式使用者是系統擁有者本人。
- 日常使用手機快速記錄消費與資金事件，桌面主要負責複盤與例外處理。
- 每週／每月需要完成對帳、估值與資產變化解釋。
- AI 可透過私有 MCP 唯讀分析，但任何正式寫入都必須由使用者在可信 UI 明確核准，並由桌面端帳務核心驗證與執行。

## 核心工作流

1. 快速記錄收入、支出、轉帳、信用卡付款與投資交易。
2. 將銀行、信用卡與券商證據和正式帳本對帳。
3. 查看帶有估值時間、品質與警告的總資產、負債及可用現金。
4. 建立可重現的週／月快照並保存調整歷史。
5. 建立並驗證備份，在故障時能安全還原到新資料目錄。

## 第一屏必須成立的體驗

- 立即看見可用現金、負債、投資市值與 provisional net worth。
- 清楚看見市場價格時間、缺價、舊價與未對帳警告。
- 手機第一屏以金額、分類、描述（選填）快速記錄；分類可從依使用頻率排序的下拉選單挑選或直接自訂，並從本機歷史成為常用選項，桌面總覽不重複日常輸入表單。
- 空資料狀態不強迫先完成帳戶設定；可先保存 Financial Event，再引導建立帳戶與期初餘額。

## 長期不做的事

- 不把它做成通用商業會計 ERP。
- 不讓 UI、MCP 或 AI 繞過帳務核心直接改資料庫。
- 不把雲端 relay 當成正式帳本。
- 不讓手機或 relay 直接寫 transaction／posting；未來手機的低風險核准仍由桌面端驗證與 commit。
- 不用推測值隱藏缺少的價格、匯率或對帳證據。

## 必須反駁的方向

- 為了方便而允許直接覆寫歷史交易或帳戶餘額。
- 在 mobile sync、備份還原或 ledger invariant 尚未驗證前加入自動 AI 寫入。
- 在沒有 provider、as-of 與 quality 時顯示看似即時的資產市值。
- 把正式個人財務資料放進 source repository、public HTTP endpoint 或一般公開 tunnel。
